# 画像変換ツール 仕様書

## 1. 概要

既存のWebToolに、画像ファイルのフォーマットを変換できる「画像変換ツール」を追加する。

ユーザーが画像ファイルを選択し、変換先のフォーマットを指定して変換を実行することで、変換後の画像をダウンロードできるようにする。

また、SVG形式については、開発用途での利用を想定し、SVGソースコードのコピー機能と、ファビコンとして利用するためのHTMLコードコピー機能を提供する。

## 2. 基本的な操作フロー

以下の操作で変換できるようにする。

1. inputタグを使用して変換元の画像ファイルを選択する。
2. 変換先のフォーマットをプルダウンから選択する。
3. 「変換」ボタンを押す。
4. 変換処理を実行する。
5. 変換成功後、変換結果をプレビュー表示する。
6. 「ダウンロード」ボタンから変換後の画像を保存する。

SVG形式に変換した場合は、ダウンロード機能に加えて、以下のコピー機能を表示する。

- SVGソースコードのコピー
- ファビコン用HTMLコードのコピー

## 3. 対応フォーマット

### 変換元

初期対応として、以下の画像形式を対象とする。

| 形式 | 拡張子 |
|---|---|
| PNG | .png |
| JPEG | .jpg / .jpeg |
| WebP | .webp |
| GIF | .gif |
| SVG | .svg |
| BMP | .bmp |

### 変換先

初期対応として、以下の形式を選択可能にする。

- PNG
- JPEG
- WebP
- GIF
- SVG

※ 実際に利用する変換処理の対応状況に応じて、選択可能な形式を制御すること。

※ 対応できない形式を選択できる状態にしないこと。

## 4. 画面構成

### 4-1. ファイル選択エリア

- inputタグのtype="file"を使用する。
- 画像ファイルを選択できるようにする。
- accept属性を利用し、対応形式を指定する。
- 選択したファイル名を表示する。
- ファイル未選択時は、未選択であることが分かる表示にする。

### 4-2. 変換先選択エリア

- プルダウン形式で変換先のフォーマットを選択できるようにする。
- 初期値はPNGとする。
- 選択した画像に対して変換できないフォーマットは選択肢から除外、または選択不可にする。
- 変換元と変換先が同じ場合は、不要な変換処理を行わないようにする。

### 4-3. 変換ボタン

- 「変換」ボタンを設置する。
- ファイル未選択時はボタンを無効化する。
- 変換処理中は二重実行を防止する。
- 処理中であることが分かる表示を行う。
- 変換失敗時は、原因が分かるエラーメッセージを表示する。

### 4-4. 変換結果エリア

変換が成功した場合に表示する。

- 変換後の画像プレビュー
- 変換後のファイル名
- 変換後のフォーマット
- ファイルサイズ
- ダウンロードボタン

変換前の画像も確認できるようにすると、変換結果を比較しやすい。

## 5. ダウンロード機能

変換後の画像をファイルとしてダウンロードできるようにする。

- 変換元のファイル名を基本的に引き継ぐ。
- 拡張子は変換後のフォーマットに合わせて変更する。
- 変換結果のデータをダウンロードする。
- 変換前の画像を誤ってダウンロードしないようにする。

例：

- input.png → input.webp
- input.jpg → input.png
- input.bmp → input.gif

## 6. SVG専用機能

変換先にSVGを選択した場合、通常のダウンロード機能に加えて、SVG専用のコピー機能を表示する。

### 6-1. SVGソースコードのコピー

変換によって生成されたSVGのソースコードを、そのままクリップボードにコピーできるようにする。

コピー対象はSVGのXML文字列全体とする。

例：

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24">
  <path d="..." />
</svg>
```

- 「SVGコードをコピー」ボタンを設置する。
- コピー後は成功したことが分かるフィードバックを表示する。
- コピーする内容は、実際に生成されたSVGデータと一致させる。

### 6-2. ファビコン用HTMLコードのコピー

SVGをファビコンとして利用するため、SVGデータをData URI形式に変換し、HTMLのlinkタグ内に直接埋め込んだコードをコピーできるようにする。

コピー対象の例：

```html
<link rel="icon" type="image/svg+xml" href="data:image/svg+xml;base64,BASE64_ENCODED_SVG_DATA">
```

※ `BASE64_ENCODED_SVG_DATA` の部分には、実際に生成されたSVGソースコードをBase64エンコードした文字列を設定すること。

- 「ファビコン用コードをコピー」ボタンを設置する。
- SVGファイルを別途配置する必要がない形式にする。
- href属性には外部ファイルのパスやURLではなく、SVGデータを埋め込んだData URIを指定する。
- Base64エンコードは、文字コードの扱いに注意し、SVGの内容が正しく復元できる方式で実装すること。
- コピーしたHTMLコードをそのままHTMLのhead要素内に貼り付けて利用できるようにする。
- コピー後は成功したことが分かるフィードバックを表示する。

## 7. SVG変換に関する仕様・注意事項

SVGは一般的な画像形式とは異なり、ベクター形式である。

そのため、ラスター画像からSVGへの変換は、単純な形式変換ではなくベクター化処理が必要となる。

### 7-1. ラスター画像からSVGへの変換

PNG・JPEG・WebP・GIF・BMPなどからSVGに変換する場合は、画像の輪郭や色を解析してSVGのパスなどに変換する処理を行う。

注意事項：

- 写真など複雑な画像は、完全な再現が難しい。
- ロゴやイラストなど、輪郭が明確な画像の方が変換に適している。
- 元画像と変換後の画像で見た目が異なる場合がある。
- 必要に応じてベクター化の品質や色数を調整できる設計を検討する。

単純にPNG画像をSVGタグ内へ埋め込むだけの処理を、ベクター化として扱わないこと。

### 7-2. SVGからラスター画像への変換

SVGからPNG・JPEG・WebP・GIFなどへ変換する場合は、SVGを指定した解像度で描画して画像化する。

- SVGの描画結果をラスター画像として出力する。
- 必要に応じて出力サイズを指定できる設計にする。
- SVGの透過背景を維持できる形式では透過を維持する。

## 8. 変換時の注意事項

### 透過情報

- PNG・WebP・SVGなど、透過に対応する形式では透過情報を可能な限り維持する。
- JPEGは透過に対応しないため、透過部分の背景色を指定できるようにする。
- JPEGへの変換時の背景色は白を初期値とする。

### アニメーション

- GIFなどのアニメーション画像を変換する場合、可能な限りアニメーションを維持する。
- アニメーションを維持できない変換では、静止画として変換されることを事前にユーザーへ通知する。
- 変換先の形式がアニメーションに対応していない場合も同様に通知する。

### ファイルサイズ

- 変換前後のファイルサイズを確認できるようにする。
- 大きすぎるファイルなど、ブラウザでの処理が難しい場合は適切なエラーを表示する。

### ファイルの安全性

- 画像の変換処理は原則としてブラウザ内で完結させる。
- 画像ファイルを外部サーバーへアップロードしない。
- SVGを扱う場合は、外部リソース参照やスクリプトなどの安全性に注意する。
- SVGのプレビューや描画時には、必要に応じて安全な方法で処理する。

## 9. デザイン・操作性

既存WebToolのデザインルールに合わせること。

- 既存のダークテーマを維持する。
- 既存のアクセントカラーを使用する。
- 既存ツールと統一感のあるレイアウトにする。
- 操作手順が直感的に理解できる配置にする。
- 変換前・変換後の状態が分かりやすい表示にする。
- エラー・処理中・変換成功などの状態を明確にする。
- 不要な装飾や複雑な操作を追加しない。

## 10. 実装上の制約

- 既存のWebToolの構成・設計・コーディング規約に従う。
- 既存機能の動作に影響を与えないこと。
- 既存の画面遷移やナビゲーションを変更しないこと。
- 画像変換機能に必要な範囲で実装すること。
- 必要に応じてライブラリを利用してよいが、導入する場合は既存環境との互換性を確認すること。
- 変換処理の実現が難しい形式については、無理に対応せず、対応範囲を明確にすること。
- 対応していない変換を、見かけ上だけ可能にしないこと。

## 11. 完了条件

- [ ] 画像ファイルを選択できる。
- [ ] 変換先のフォーマットをプルダウンで選択できる。
- [ ] 変換ボタンで画像を変換できる。
- [ ] 変換後の画像をプレビュー表示できる。
- [ ] 変換後の画像をダウンロードできる。
- [ ] ダウンロード時のファイル名と拡張子が正しい。
- [ ] SVGのソースコードをコピーできる。
- [ ] SVGをData URIとして埋め込んだファビコン用linkタグをコピーできる。
- [ ] コピーしたファビコン用コードが外部SVGファイルに依存しない。
- [ ] 変換できない形式や失敗時に適切なメッセージが表示される。
- [ ] 透過情報やアニメーションの扱いが適切である。
- [ ] 既存のWebToolの機能に影響がない。
- [ ] PC・スマートフォンの両方で操作できる。

## 12. 最終的な目標

画像ファイルを選択し、変換先を指定するだけで簡単にフォーマット変換できるツールを実現する。

特にSVGについては、画像ファイルとして保存するだけでなく、ソースコードや、SVGデータを直接埋め込んだファビコン用HTMLコードをすぐに取得できるようにし、Web開発時に便利なツールにする。
